# GRANDCANY0N Portfolio

孙嘉豪的个人主页与项目索引，面向简历投递和技术面试场景。页面按简历式层级展示教育、技能、实习、项目、科研与荣誉，并提供“复杂文档解析与证据检索”和“QQBot 校园生活 Agent”两个项目详情页。

## Local development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

静态站点输出到 `dist/client/`，由仓库的 `gh-pages` 分支发布至 [grandcany0n.github.io](https://grandcany0n.github.io/)。
