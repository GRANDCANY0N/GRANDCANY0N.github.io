# GRANDCANY0N Portfolio

孙嘉豪的个人主页与项目索引，面向简历投递和技术面试场景。页面包含个人简介、能力概览、项目入口、研发经历，以及 DocTrace 项目的独立详情页。

## Local development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
```

静态站点输出到 `dist/client/`，由仓库的 `gh-pages` 分支发布至 [grandcany0n.github.io](https://grandcany0n.github.io/)。
